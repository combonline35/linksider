# Простая интеграция с amoCRM

Простой скрипт для проверки подключения к API amoCRM.

## Настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка в amoCRM

1. Войдите в свой аккаунт amoCRM
2. Перейдите в настройки → Интеграции → Разработка
3. Создайте новое приложение со следующими параметрами:
   - **Redirect URI**: `https://localhost`
   - **Права доступа**: выберите нужные (минимум - чтение контактов)

### 3. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните ваши данные в файле `.env`:

```env
AMOCRM_DOMAIN=ваш-поддомен.amocrm.ru
AMOCRM_CLIENT_ID=ваш_client_id
AMOCRM_CLIENT_SECRET=ваш_client_secret
AMOCRM_REDIRECT_URI=https://localhost
AMOCRM_ACCESS_TOKEN=ваш_access_token
```

## Использование

### Первый запуск (получение токена)

Если у вас еще нет access token:

```bash
python amocrm_integration.py
```

Скрипт покажет URL для авторизации. Откройте его в браузере, авторизуйтесь, и скопируйте код из URL обратно в терминал.

### Обычное использование

После получения токена скрипт автоматически проверит:
- ✅ Подключение к API
- ✅ Информацию об аккаунте  
- ✅ Получение списка контактов

## Что проверяет скрипт

1. **Подключение к API** - проверяет доступность API и корректность токена
2. **Информация об аккаунте** - получает базовую информацию о вашем amoCRM
3. **Список контактов** - тестирует получение данных из CRM

## Возможные ошибки

### "Не все обязательные переменные окружения установлены"
- Проверьте файл `.env`
- Убедитесь, что заполнены `AMOCRM_DOMAIN`, `AMOCRM_CLIENT_ID`, `AMOCRM_CLIENT_SECRET`

### "Access token не установлен"
- Запустите скрипт для получения токена
- Добавьте полученный токен в `.env` файл

### "Ошибка подключения: 401"
- Токен истек или неверный
- Получите новый токен через авторизацию
